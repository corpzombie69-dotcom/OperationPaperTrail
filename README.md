# Paper Trail

Catch phrases, quotes, and sayings from anywhere and anytime. Type a saying in, and it traces the earliest documented use, the story behind it, and whether it's still in circulation today.

## Disclaimer

Origin stories are researched live by AI using web search — they're good for trivia night, not for anything you'd bet money on. Always double-check anything important against a real source.
